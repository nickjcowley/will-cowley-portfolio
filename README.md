# Will Cowley – Engineering Portfolio

Static website (HTML + CSS, no build step) published with GitHub Pages.

- `index.html` – page content
- `styles.css` – styling
- `images/` – photos and renders (add new ones here and reference them from `index.html`)

## Moving to Will's own GitHub account
Settings → General → Danger Zone → Transfer ownership → enter Will's username.
Then in the new repo: Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
The address changes from `nickjcowley.github.io/will-cowley-portfolio` to `<will's-username>.github.io/will-cowley-portfolio`
(or rename the repo to `<will's-username>.github.io` for a shorter address).
